## Огляд

Модуль надає `useAcpAgent` для підключення ACP agent у межах застосунку. Він визначає робочу базу через домашній каталог користувача, а за його відсутності переходить на `.`.

Анкори: `useAcpAgent`, `.`

## Поведінка

1. useAcpAgent створює in-app ACP agent gateway для роботи з agent context у межах застосунку.
2. useAcpAgent визначає робочу базу від домашнього каталогу користувача; якщо середовище його не надає, переходить на `.` як fallback.
3. useAcpAgent передає у gateway каталог доступних інструментів і поточну базу виконання, щоб агент працював із контекстом застосунку, а не з жорстко зашитим workspace root.
4. useAcpAgent повертає готовий gateway для подальшої взаємодії з agent state, журналом і операціями погодження/відповіді в межах ACP.
