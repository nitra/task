## Огляд

Модуль формує глобальний PR Inbox із відкритих GitHub pull requests для поточного користувача. Він використовує тільки локально авторизований CLI `gh` і не зберігає токени чи вміст приватних змін.

## Поведінка

- Шукає відкриті PR, де користувач є автором, запитаним reviewer або assignee, та прибирає дублікати між цими вибірками.
- Для авторських PR визначає наступну дію за GitHub-фактами: draft, `Changes requested`, конфлікт, провалений CI або очікування reviewer/мейнтейнера.
- Для PR на review і призначених PR повертає окремі категорії, щоб UI міг показати їх без евристик.
- Повертає лише метадані, посилання, перелік запитаних reviewer та провалені checks.
- За запитом UI отримує окремий read-only контекст одного PR для LLM-резюме: body, файли, reviews, comments і CI status.

## Гарантії поведінки

- Усі GitHub-запити read-only.
- Дані PR передаються в LLM тільки після явного запиту користувача в UI.
- Помилка `gh` або невалідна відповідь повертається в UI як помилка завантаження, без частково вигаданих даних.
