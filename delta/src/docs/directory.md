## Огляд

Файл забезпечує роботу з довідником користувачів через парсинг, форматування та очищення вмісту директорій. Використовуються `parseDirectory` та `formatDirectory` для обробки структури, `setDirectoryEntry` для оновлення записів та `emptyDirectory` для повного очищення. `displayName` забезпечує відображення імен, а локальні механізми захисту запобігають критичним помилкам під час виконання операцій.

## Поведінка

Робота з довідником базується на об'єкті, де ключами є ідентифікатори користувачів. Дані з файлу `directory.json` завантажуються через парсинг сирого тексту, що забезпечує створення порожнього об'єкта у разі відсутності файлу або помилок у його структурі. Для формування стабільного вигляду файлу при записі використовується сортування за ключами.

Оновлення даних відбувається через створення нових версій об'єкта, де кожен запис нормалізується для збереження консистентності полів. При зміні даних через патч-оновлення, існуючі значення зберігаються, якщо вони не були замінені новими. Для відображення користувачів у інтерфейсі використовується логіка підстановки: якщо для ідентифікатора не задано ім'я, він використовується як текстовий замінник. Цей механізм забезпечує сумісність із логікою, що використовує `device-registry.json` та інші конфіги, де ідентифікатор є первинним ключем.

## Публічний API

- parseDirectory — Розбирає сирий текст `directory.json` — відсутній/битий файл повертає
порожній обʼєкт (не кидає), той самий інваріант, що `device-registry.js`/
`knowledge.js`: відсутність довідника — стан «ще ніхто не заповнив
display-імена», не помилка.
- formatDirectory — Серіалізує довідник у pretty-print JSON з кінцевим переносом рядка,
ключі відсортовані (стабільний diff у git — довідник комітиться).
- setDirectoryEntry — Записує (чи оновлює) запис одного handle — pure-функція (повертає новий
обʼєкт, не мутує вхідний), part update (лише передані поля змінюються,
решта лишається — read-merge-write на рівні одного запису).
- displayName — Display-імʼя для handle — «підставляється в усі екрани (черга, карта,
Довіряю) з фолбеком на handle» (M4 п.1). Немає запису/імені — сам handle
(ніколи не порожній рядок для валідного handle), `null`/`undefined`
handle — `null` (немає кого показувати).
- emptyDirectory — видаляє вміст папки, залишаючи саму директорію і її структуру.

Код використовує конфіги, на які спирається код: directory.json, device_key.json, knowledge.json, config.json, directory.example.json, device-registry.json.
