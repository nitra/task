## Огляд

Файл забезпечує формування звітів про історію активності пристроїв та статистику завершених пар запитів із підписами за допомогою `deriveTrackRecord`.

## Поведінка

1. Збір даних з усіх доступних директорій з рішеннями для формування списку завершених пар запитів та підписів.
2. Атрибуція підписантів у кожній парі на основі записів із `device-registry.json`.
3. Визначення випадків перекриття рішень, коли пізніші людські відповіді змінюють результат попередніх моделей.
4. Фільтрація рішень за конкретним ідентифікатором пристрою для формування історії активності.
5. Підрахунок загальної кількості рішень, розподілу за типами та статистики перекриттів з використанням даних з `approval.json`.
6. Формування звіту про активність та послідовність дій для заданого пристрою.

## Публічний API

- deriveTrackRecord — Дериваційний трек-рекорд одного `handle` (моделі) — читає всі
`decisions/`-run-и, знаходить рішення, підписані ЦИМ handle (за
атрибуцією реєстру пристроїв), рахує активність/послідовність.
