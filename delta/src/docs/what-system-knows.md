## Огляд

Файл формує зріз даних про стан системи для конкретного користувача за допомогою buildWhatSystemKnows. Результат містить актуальний стан знань системи та відфільтровані сповіщення, включаючи нагадування про SLA, ескалації та пакетні повідомлення. Додатково надає дані про роль, публічний ключ та дату реєстрації користувача з реєстру пристроїв.

## Поведінка

1. Формує зріз даних про стан системи для конкретного користувача, агрегуючи інформацію з бази знань, логів сповіщень та реєстру пристроїв.
2. Використовує наявні записи бази знань для розрахунку загальної кількості записів, створення цифрового відбитка та визначення тренду розуміння.
3. Фільтрує сповіщення, залишаючи лише ті, що адресовані користувачу, для відображення:
    - загальної кількості повідомлень;
    - нагадувань про виконання SLA;
    - сповіщень про ескалацію;
    - пакетних повідомлень.
4. Поєднує дані з реєстру пристроїв для відображення ролі користувача, його публічного ключа та дати реєстрації.

## Публічний API

- buildWhatSystemKnows — Агрегує усі джерела «що система знає про мене» в один зріз для одного
`handle` — лише МОЇ записи скрізь (фільтр за `to`/`handle` на кожному
джерелі, ЖОДНОГО чужого запису не просочується).

## Сценарії використання

- Тестування buildWhatSystemKnows:
    - чистий агрегатор — БЕЗ вхідних даних лишається порожнім, не кидає;
    - база знань — digest/trend деривовані через ту саму knowledge.js-логіку, entryCount;
    - нотифікації — лише МОЇ (фільтр за to), розбиті на pingsToMe/escalatedFromMe/batchedNow; чужі нотифікації НІКОЛИ не просочуються у зріз;
    - реєстр — pubkey/role МОГО handle з device-registry.js, чужий запис не просочується.
