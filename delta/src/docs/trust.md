## Огляд

Файл керує рівнем зухвалості через зміну масштабу мандатів та формування перегляду стану довіри. Він дозволяє виконувати послідовне розширення або звуження мандатів за допомогою `widenMandateOneStep` та `narrowMandateOneStep` з контролем досягнення меж через `isAtWidenCeiling` та `isAtNarrowFloor`. Використання `audacityOf` разом із `AUDACITY_LEVELS` та `AUDACITY_DESCRIPTIONS` визначає поточний стан, а `deriveTrustView` та `withMandateReplaced` забезпечують перехід між станами через `isAtWidenCeiling` та `isAtNarrowFloor`.

## Поведінка

Рівень зухвалості визначається на основі нормалізованого мандата, де за замовчуванням встановлюється мінімальний рівень. Зміна масштабу мандата відбувається шляхом послідовного підвищення або зниження рівня зухвалості. Якщо досягнуто межі (стелі або дна), подальші кроки призводять до зміни фінансових параметрів через фолбек-осі.

Перегляд стану довіри формується шляхом агрегації даних із файлів мандатів, реєстру пристроїв та історії рішень. Цей процес дозволяє отримати зріз актуальних мандатів користувача разом із їхнім трек-рекордом.

Оновлення мандатів у файлі виконується через заміну конкретного запису з інкрементом версії файлу, зберігаючи інші дані незмінними. Перевірка досягнення меж дозволяє керувати доступністю дій у інтерфейсі: якщо мандат перебуває на стелі або на дні за обома осми, подальші розширення чи звуження стають неможливими.

## Публічний API

- deriveTrustView — Дериваційний зріз екрана «Довіряю» — мої ШІ-мандати (`escalates_to === handle`)
з трек-рекордом кожного.
- narrowMandateOneStep — Звужений мандат — audacity на один щабель нижче; на дні (`low`) — фолбек
на `budget_eur` (÷2, мінімум 0). MVP-скоуп однієї осі, див. заголовок модуля.
- widenMandateOneStep — Розширений мандат — audacity на один щабель вище; на стелі (`high`) —
фолбек на `budget_eur` (×1.5, мінімум +50 від нуля). MVP-скоуп однієї осі.
- isAtWidenCeiling — true — мандат уже на стелі за обома фолбек-осями (audacity high І
budget_eur відсутній ceiling) — UI дизейблить кнопку «розширити».
- isAtNarrowFloor — true — мандат уже на дні за обома фолбек-осями (audacity low І
budget_eur 0) — UI дизейблить кнопку «звузити».
- AUDACITY_LEVELS — набір рівнів зухвалості.
- AUDACITY_DESCRIPTIONS — текстові описи рівнів зухвалості.
- audacityOf — повертає поточний рівень зухвалості.
- withMandateReplaced — створює нову версію з заміненим мандатом.
