## Огляд

Інтерфейс надає доступ до площин конституції для візуалізації мандатів, роботи з чергою рішень, базою знань та моніторингу спостережень. Панічна кнопка перемикає стан kill-switch для керування статусом доступу.

## Поведінка

1. Перегляд доступних площин конституції через навігацію між розділами:
    - Візуалізація мандатів.
    - Робота з чергою рішень.
    - Перегляд довіри.
    - Робота з базою знань.
    - Моніторинг спостережень.
    - Перегляд незручної правди.
    - Перегляд звітів.
2. Використання панічної кнопки для миттєвого керування станом kill-switch:
    - При активації кнопки стан перемикається без підтвердження, що дозволяє негайно змінити статус доступу.
    - При деактивації кнопки стан повертається до базового режиму.
    - Статус кнопки синхронізується з бекендом при завантаженні інтерфейсу та після кожного натискання.
