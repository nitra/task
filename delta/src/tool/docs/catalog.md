## Огляд

Файл надає TOOLS для управління персональною ідентифікацією, робочим простором та мандатами користувача. Він дозволяє пропонувати зміни параметрів мандатів.

## Поведінка

1. Ідентифікація та робоче середовище:
- `whoami` дозволяє дізнатися поточну ідентифікацію користувача.
- `set_identity` зберігає ідентифікатор для подальшої роботи.
- `mandates_dir` повертає шлях до кореня робочого простору.
- `set_mandates_dir` встановлює шлях до робочого простору.

2. Робота з мандатами та чергами:
- `mandates_show` зчитує структуру мандатів та формує персоналізований зріз даних.
- `decisions_show` формує чергу активних запитів на прийняття рішень.
- `decision_quiz` створює або відображає питання для перевірки знань щодо варіанту рішення.
- `decision_approve` завершує процес квізу: правильна відповідь на останнє питання фіналізує квіз, записує дані у персональну базу знань та створює підписаний `NNNN-approval.json`.

3. Керування пристроєм та конфігурацією:
- `device_pubkey` забезпечує наявність ключа пристрою та повертає його публічну частину.
- `llm_config` зчитує налаштування локального endpoint для генерації питань.
- `set_llm_config` зберігає нові налаштування endpoint.

4. База знань та рівень довіри:
- `knowledge_show` надає доступ до персональної бази знань, що зберігається поруч із `config.json`, відображаючи прогрес розуміння та підсумки.
- `trust_show` показує список мандатів, що належать користувачу, та його історію активності.

5. Зміна мандатів:
- `mandate_narrow` миттєво звужує параметри мандата без додаткових перевірок.
- `mandate_widen_propose` створює чернетку пропозиції щодо розширення мандата, яка потрапляє в чергу запитів на рішення.
- `ai_petition` дозволяє моделі ініціювати запит на розширення власного мандата з підписом пристрою.
- `mandate_change_apply` фіналізує зміни після підпису делегатора, перевіряючи валідність і застосовуючи мутацію до файлів.
