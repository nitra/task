## Огляд

Файл ініціалізує середовище для роботи з LLM шляхом завантаження конфігурацій, ключів пристрою та мандатів. Виконує реєстрацію пристрою в реєстрі та підготовку даних для [dispatch]().

## Поведінка

1. Виконується завантаження конфігурацій: зчитується налаштування LLM-ендпоінта, завантажується або генерується ключ пристрою, а також зчитуються мандати та база знань.
2. Визначаються шляхи до робочих директорій та реєстру пристроїв.
3. Перевіряється наявність підпису в `device-registry.json` та виконується реєстрація пристрою, якщо це необхідно.
4. Виконується завантаження або генерація ключа моделі для забезпечення локального зберігання секретів.
5. Виконується виконання логіки тула з використанням отриманих конфігів, знань та ключів.
6. Результати роботи з файлами та ключами (зокрема `device_key.json` та `approval.json`) забезпечують цілісність процесу згідно з бізнес-правилами.
