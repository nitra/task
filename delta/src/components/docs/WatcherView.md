## Огляд

Файл ініціює оновлення стану елементів через `rescan` та `rescanDrift`. Він передає налаштування тихих годин та параметри взаємодії з картками рішень між інтерфейсом і логікою обробки.

## Поведінка

Процес оновлення даних ініціюється через rescan або rescanDrift, що призводить до перерахунку стану елементів. Результати обробки відображаються через візуальні мітки або іконки сповіщень. Взаємодія з картками рішень та збереження налаштувань тихих годин виконуються через делеговані методи, що забезпечують передачу даних від інтерфейсу до логіки обробки.

## Публічний API

- rescan — ініціює повний цикл пошуку та збору даних для актуалізації стану об'єктів згідно з [specifications]
- rescanDrift — визначає відхилення поточного стану від [expected state]
