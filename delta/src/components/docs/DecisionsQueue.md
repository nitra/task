## Огляд

Файл відображає список відкритих запитів на прийняття рішень згідно з мандатом користувача.

## Поведінка

Черга відображає відкриті запити на прийняття рішень, що відповідають поточному мандату користувача. Дані зчитуються з файлової структури воркспейсу на основі налаштованої ідентичності.

Для отримання актуального стану черги виконується `refreshConfig` для оновлення конфігураційних даних, після чого запускається `rescan` для формування списку активних розвилок. Коли рішення приймається, елемент автоматично видаляється з черги.

## Публічний API

- rescan — виявляє зміни у файловій структурі та формує список активних розвилок
- refreshConfig — застосовує нові параметри з конфігураційних файлів

## Гарантії поведінки

- Власних операцій запису у файлі немає; виклики імпортованих модулів можуть писати.
