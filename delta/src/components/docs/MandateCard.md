## Огляд

Відображає дані про `mandate`, `mine` та `displayName`. Використовує технічний ідентифікатор для ідентифікації власника.

## Поведінка

Компонент відображає інформацію про мандат, використовуючи дані з об'єкта `mandate`. Якщо для відображення імені надано `displayName` (наприклад, з конфігу `directory.json`), воно використовується як основне, а технічний ідентифікатор власника відображається як допоміжний текст. Якщо `mine` активовано, картка позначається як власний мандат. Візуалізація включає відображення сфер впливу, типів рішень та встановлених порогів (бюджет, ризик, незворотність, зухвалість). Картка також відображає зв'язок ескалації або статус кореневого мандата.

## Публічний API

- mandate — встановлює обов'язкові вимоги до об'єкта згідно з правилами, визначеними у directory.json
- mine — витягує необхідні дані з джерела для подальшої обробки
- displayName — формує зрозумілу назву для відображення користувачу
