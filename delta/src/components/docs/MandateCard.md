## Огляд

Відображає стан [mandate](link-to-mandate) та [mine](link-to-mine), включаючи власника, область дії та встановлені пороги.

## Поведінка

Візуалізує інформацію про мандат, відображаючи власника, тип мандату та його статус. Дані про власника, область дії та встановлені пороги відображаються через відповідні мітки та чипи. Якщо мандат є кореневим, відображається відповідна позначка, якщо ж він передбачає ескалацію — вказується ціль ескалації. Використання власного мандата супроводжується візуальним виділенням картки.

## Публічний API

- mandate — визначає обов'язкові умови, які мають бути дотримані для успішного завершення операції
- mine — збирає та витягує необхідні дані з наданого контексту для подальшої обробки

## Гарантії поведінки

- Власних операцій запису (ФС/БД) у файлі немає; виклики імпортованих модулів можуть писати.
