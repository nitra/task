## Огляд

Діалог використовує `modelValue` та `update:modelValue` для керування ідентифікатором, а також `initialHandle` та `initialDir` для визначення початкових параметрів шляху. Після ініціалізації через `started` параметри застосовуються для запуску процесу.

## Поведінка

При запуску діалогу використовується `initialHandle` та `initialDir` для заповнення полів ідентифікації та шляху до мандатів. Після завершення налаштування через `modelValue` керує видимістю вікна, а дані передаються у систему. При натисканні кнопки завершення відбувається запуск процесу реєстрації: якщо введено ідентифікатор, він стає актуальним для системи, якщо вказано шлях — він встановлюється як робоча директорія. Після цього діалог закривається через `update:modelValue`, а система сповіщає про завершення через `started`.

## Публічний API

- modelValue — забезпечує роботу з поточним значенням
- initialHandle — задає початкове значення для обробника
- initialDir — визначає початковий напрямок
- update:modelValue — оновлює значення у відповідності до зовнішніх змін
- started — вказує на запуск процесу
