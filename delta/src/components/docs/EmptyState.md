## Огляд

Компонент відображає стан налаштування шляху до мандатів. Він показує наявність заданого шляху через `configured` або відсутність файлів, а також надає можливість виконати `setup`.

## Поведінка

Стан відображення залежить від прапорця налаштування шляху до мандатів. Якщо шлях не задано, компонент інформує про необхідність конфігурації. Якщо шлях налаштовано, він повідомляє про відсутність мандатів у файлі. Виклик дії з налаштування дозволяє ініціювати процес конфігурації.

## Публічний API

- configured — застосовує параметри конфігурації
- setup — виконує підготовку системи до роботи

## Гарантії поведінки

- Власних операцій запису (ФС/БД) у файлі немає; виклики імпортованих модулів можуть писати.
