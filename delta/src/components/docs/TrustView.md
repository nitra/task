## Огляд

Файл дозволяє керувати ШІ-мандатами користувача, зокрема оновлювати їхній перелік або звужувати сферу дії. Для актуалізації стану мандатів використовується `rescan`.

## Поведінка

1. Оновлення списку активних мандатів шляхом повторного зчитування даних.
2. Перегляд переліку ШІ-мандатів, що належать користувачу, з їхніми параметрами: рівнем зухвалості, бюджетними чи ризиковими порогами та типом наслідків.
3. Аналіз трек-рекорду кожного мандата: кількості прийнятих рішень, частоти ручного перегляду (override) та історії останніх операцій.
4. Звуження мандата для обмеження його сфери дії.
5. Пропозиція розширення мандата, що створює чергу на розгляд власника для подальшого проходження квіз-гейта.

## Гарантії поведінки

- Власних операцій запису (ФС/БД) у файлі немає; виклики імпортованих модулів можуть писати.
