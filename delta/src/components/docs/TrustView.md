## Огляд

Файл дозволяє керувати персональними ШІ-мандатами користувача, надаючи доступ до їхніх параметрів та актуального стану. Інструментарій забезпечує перегляд існуючих мандатів та ініціювання їхнього розширення через механізм черги на розгляд власника. Функція `rescan` оновлює дані про мандати згідно з поточним станом.

## Поведінка

1. Відображення списку ШІ-мандатів, які належать користувачу за рівнем доступу.
2. Перегляд детальної інформації щодо кожного мандата: опису зухвалості, встановлених порогів (бюджет, ризик, тип змін) та історії виконаних рішень.
3. Аналіз трек-рекорду для оцінки активності та частоти ручного перегляду рішень.
4. Виконання звуження мандата для обмеження його обсягу.
5. Виконання пропозиції щодо розширення мандата, що створює чергу на розгляд власника.
6. Оновлення списку мандатів через примусове пересканування даних.

## Гарантії поведінки

- Власних операцій запису (ФС/БД) у файлі немає; виклики імпортованих модулів можуть писати.
