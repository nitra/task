## Огляд

Файл дозволяє переглядати параметри повноважень, історію прийнятих рішень та частоту ручних перекриттів персональних ШІ-мандатів. Функція `rescan` оновлює стан мандатів для актуалізації їхнього статусу.

## Поведінка

1. Перегляд списку ШІ-мандатів, які належать користувачу (де він є кінцевим отримувачем повноважень).
2. Відображення параметрів кожного мандата: бюджету, ризиків, характеру змін та рівня зухвалі.
3. Перегляд історії виконання: загальної кількості прийнятих рішень, частоти людських перекриттів (overrides) та останніх активностей.
4. Виконання звуження мандата для зменшення його обсягу.
5. Виконання пропозиції щодо розширення мандата, що створює чергу на розгляд власника для проходження квіз-гейта.
6. Оновлення актуального стану списку мандатів через примусове пересканування.

## Гарантії поведінки

- Власних операцій запису (ФС/БД) у файлі немає; виклики імпортованих модулів можуть писати.
