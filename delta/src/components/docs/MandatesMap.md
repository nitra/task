## Огляд

Візуалізує дерево мандатів на основі файлу `mandates.yaml`. Містить персональні, ШІ-мандати та повну карту зрізу даних для поточної ідентичності.

## Поведінка

1. Візуалізує дерево мандатів на основі файлу `mandates.yaml`.
2. Пропонує налаштування середовища через діалогове вікно, якщо система ще не налаштована або відсутній шлях до даних.
3. Розподіляє відображення на три зони: персональні мандати користувача, ШІ-мандати та повну карту мандатів.
4. Відображає дані згідно з ідентичністю користувача.
5. Відображає ланцюг ескалації.
6. Повідомляє про відсутність запису для поточної ідентичності, якщо користувач не входить у дерево мандатів.
7. Дозволяє оновити дані карти шляхом повторного сканування файлів.

## Гарантії поведінки

- Власних операцій запису (ФС/БД) у файлі немає; виклики імпортованих модулів можуть писати.
