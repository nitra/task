## Огляд

Візуалізація карти мандатів та відображення власників базуються на даних з `directory.json`. Система відображає ланцюг ескалації у зоні особистого мандату.

## Поведінка

1. Відображення карти мандатів та керування ідентичністю:
   - При запуску система перевіряє наявність налаштованої ідентичності та шляху до мандатів.
   - Якщо конфігурація відсутня, пропонується процес первинного налаштування.
   - Користувач може змінити свою ідентичність, що оновлює зріз відображення карти.
   - Після зміни параметів середовища виконується повне перечитання конфігів, сканування файлів та оновлення довідника display-імен з файлу directory.json.

2. Управління відображенням імен:
   - В адмін-секції доступний список усіх власників мандатів.
   - Користувач може редагувати display-імена для кожного власника, що зберігається у файлі directory.json.
   - Встановлені імена використовуються для відображення по всій карті замість технічних ідентифікаторів.

3. Робота з мандатами:
   - Карта розділена на зони: особистий мандат, ШІ-мандати та повний перелік усіх мандатів.
   - У зоні власного мандата відображається ланцюг ескалації, що показує зв'язок між власником та поточним користувачем.
   - Якщо для поточної ідентичності не знайдено записів, система інформує про відсутність зв'язку з деревом мандатів.

## Гарантії поведінки

- Власних операцій запису (ФС/БД) у файлі немає; виклики імпортованих модулів можуть писати.
