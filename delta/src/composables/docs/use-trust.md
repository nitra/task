## Огляд

Файл дозволяє звужувати сферу дії мандатів до одного рівня або ініціювати процес їхнього розширення через чергу запитів на людське підтвердження. Використовується `useTrust`.

## Поведінка

1. Отримання конфігурації: завантаження даних про поточну ідентичність та шлях до робочого простору.
2. Оновлення списку мандатів: перечитування актуального стану ШІ-мандатів, що належать користувачу, з файлової системи.
3. Звуження мандата: миттєве обмеження сфери дії конкретного мандата до одного щабля.
4. Пропозиція розширення: створення черги на розширення мандата, що генерує запит на прийняття рішення для подальшого людського підпису.

## Гарантії поведінки

- Власних операцій запису (ФС/БД) у файлі немає; виклики імпортованих модулів можуть писати.
