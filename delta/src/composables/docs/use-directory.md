## Огляд

Файл працює з довідником воркспейсу на основі даних з `directory.json`. Через `useDirectory` можна отримувати відображувані імена та оновлювати дані для ідентифікаторів.

## Поведінка

1. Завантаження даних з файлу directory.json для отримання актуального списку відомостей воркспейсу.
2. Оновлення або створення записів для конкретних ідентифікаторів у межах воркспейсу.
3. Отримання відображуваних імен на основі отриманих даних або використання ідентифікаторів як запасних варіантів.
4. Управління станом завантаження та помилок під час роботи з довідником.

## Гарантії поведінки

- Власних операцій запису (ФС/БД) у файлі немає; виклики імпортованих модулів можуть писати.
