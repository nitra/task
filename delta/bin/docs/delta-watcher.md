## Огляд

Інструмент виявляє зміни у файлах у межах структури воркспейсу, використовуючи локальні fail-safe гілки для запобігання поширенню помилок назовні.

## Поведінка

1. Визначається робоча директорія для сканування на основі переданого аргументу або налаштування `mandates_dir` із `config.json`.
2. Зчитуються параметри тихої години з `config.json` для керування часом виконання завдань.
3. Виконується пошук директорій з рішеннями у структурі воркспейсу.
4. Проводиться сканування файлів у знайдених директоріях для аналізу змін.
5. Формується звіт про результати сканування, який виводиться у стандартний потік виводу.

## Гарантії поведінки

- Містить локальні fail-safe гілки; інші помилки можуть поширюватися назовні.
